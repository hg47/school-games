Приборкай безлад

Допоможи Біту впорядкувати файли. Позначай виконані кроки.

Один клік — вибрати. Подвійний клік — відкрити. Ctrl + клік — кілька об'єктів. Права кнопка — меню дій.

Копіювання залишає оригінал. Переміщення змінює папку. Ярлик — лише покажчик на файл. З флешки видаляється одразу, без Кошика.
