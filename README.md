# Сайт ігор — інструкція

Свій міні-сайт з навчальними іграми: діти відкривають за посиланням (без логіна),
проходять гру, отримують **оцінку 1-12**, а результати збираються у **твою Google-таблицю**.

**Склад:**
- `index.html` — головна сторінка-каталог «Мої ігри»
- `games/naved-lad.html` — гра «Наведи лад» (5 клас)
- `stats.js` — вхід за кодом+ім'ям, підрахунок оцінки, надсилання результату
- `config.js` — сюди вставляється адреса приймача результатів
- `apps-script.gs` — код для Google-таблиці (приймач + коди + підсумок)

---

## Частина 1. Виклад сайту на GitHub Pages (діти відкривають за посиланням)

1. На **github.com** → **New repository** → назва напр. `school-games`, тип **Public**, Create.
2. **Add file → Upload files** → перетягни сюди `index.html`, `config.js`, `stats.js` і **папку**
   `games` (з `naved-lad.html`). *(`apps-script.gs` і `README.md` завантажувати не обов'язково —
   вони для тебе, не для сайту.)* → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → гілка `main`, папка `/root` → **Save**.
4. За хвилину сайт буде за адресою:
   `https://<твій-нік>.github.io/school-games/`
5. Посилання дітям:
   - на каталог: `https://<нік>.github.io/school-games/`
   - одразу на гру: `https://<нік>.github.io/school-games/games/naved-lad.html`

> Змінив файл (напр. `config.js`)? Просто завантаж його знову на GitHub — сайт оновиться сам.

---

## Частина 2. Статистика: Google-таблиця + Apps Script

1. Створи нову **Google Таблицю** (це твоя приватна база результатів).
2. **Розширення → Apps Script**. Видали те, що там є, і встав увесь код з `apps-script.gs`. Збережи.
3. Згори обери функцію **`setup`** і натисни **Run** (▶). Дозволь доступ (це твій акаунт).
   Створяться вкладки **Учні**, **Результати**, **Підсумок** і меню.
4. Онови сторінку таблиці — вгорі з'явиться меню **«Ігри»**.
5. **Deploy → New deployment** → тип **Web app** → **Execute as: Me**,
   **Who has access: Anyone** → **Deploy** → скопіюй **Web app URL** (закінчується на `/exec`).
6. Встав цей URL у файл **`config.js`**:
   ```js
   window.SCHOOL_STATS_URL = "https://script.google.com/macros/s/AKfyc..../exec";
   ```
   і **завантаж `config.js` знову на GitHub** (Частина 1, крок 2).

> ⚠️ Якщо пізніше зміниш код у Apps Script — треба **Deploy → Manage deployments → (олівець) →
> Version: New version → Deploy**, інакше працюватиме стара версія.

---

## Частина 3. Коди учнів

1. На вкладці **«Учні»** впиши **Клас** і **ПІБ** кожного учня (стовпці A, B).
2. Меню **«Ігри» → «Згенерувати коди для учнів»** — у стовпці **Код** з'являться короткі коди
   (напр. `K7QX`).
3. **Роздай кожному його код приватно** — через індивідуальне завдання/повідомлення в Google
   Classroom (не в спільний чат). Дитина вводить свій код + ім'я при вході в гру.

> Код прив'язує результат до конкретного учня. Ім'я дитина вводить сама (для звірки/вітання).

---

## Частина 4. Оцінки та перенос у журнал «Мрія»

- Кожен результат падає у вкладку **«Результати»** (усі спроби, з часом).
- Меню **«Ігри» → «Оновити підсумок»** → вкладка **«Підсумок»** показує **кращий бал (1-12)**
  кожного учня по кожній грі (у гри дозволено **2 спроби**, зараховується краща).
- Переносиш оцінки у **Мрію вручну** (масового імпорту в неї зазвичай немає). «Підсумок»
  відсортований за класом і ПІБ — зручно вносити.
- Шкалу % → бал можна змінити в одному місці — у `stats.js`, масив `SCALE` (скажи мені — підправлю).

---

## Приватність

- Публічний репозиторій GitHub **не містить списків дітей** — імена вводяться в грі й зберігаються
  лише у **твоїй приватній** Google-таблиці.
- Коди роздавай приватно. Збираємо мінімум: код, ім'я, клас, гра, бал, час.
- Оцінка «за активність» — гра клієнтська, тож не для «контрольної» честності (про це говорили).

---

## Як додати нову гру (пізніше)

1. Поклади новий `назва.html` у папку `games/`.
2. У `<head>` додай `<script src="../config.js"></script>` і `<script src="../stats.js"></script>`.
3. Наприкінці гри виклич `window.SchoolGame.submit("id-гри", очки, максимум)` — покаже оцінку й
   надішле результат.
4. Додай картку гри в `index.html`.

*(Найпростіше — попроси мене зібрати нову гру одразу за цим шаблоном.)*
