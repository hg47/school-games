САЙТ ІГОР — коротка пам'ятка (plain text, на всяк випадок)
=========================================================
Повна детальна інструкція — у файлі README.md (поруч).

ЩО ЦЕ
Свій міні-сайт з навчальними іграми. Діти відкривають за посиланням (без логіна),
вводять свій КОД + ІМ'Я, проходять гру, отримують ОЦІНКУ 1-12. Результати
збираються у приватну Google-таблицю. Оцінка "за активність" (2 спроби, зараховується краща).

ФАЙЛИ
  index.html            - каталог "Мої ігри" (головна)
  games/naved-lad.html  - гра "Наведи лад" (5 клас, тема ОС/файли/папки)
  stats.js              - вхід код+ім'я, підрахунок балу 1-12, надсилання результату
  config.js             - СЮДИ вставити адресу приймача (window.SCHOOL_STATS_URL = "...")
  apps-script.gs        - код для Google-таблиці (коди учнів + приймач + Підсумок)
  README.md             - докладна покрокова інструкція
  readme.txt            - цей файл

ЯК ЗАПУСТИТИ (коротко, деталі в README.md)
  1) GitHub: створити публічний репозиторій -> завантажити файли (index.html, config.js,
     stats.js, папку games) -> Settings -> Pages -> увімкнути. Адреса:
     https://<нік>.github.io/<репо>/
  2) Google Таблиця: Розширення -> Apps Script -> вставити apps-script.gs -> Run setup
     -> Deploy as Web app (Execute as: Me, Access: Anyone) -> скопіювати URL (/exec)
     -> вставити URL у config.js -> перезалити config.js на GitHub.
  3) Вкладка "Учні": вписати Клас+ПІБ -> меню "Ігри" -> "Згенерувати коди" -> роздати коди
     дітям приватно (через Classroom індивідуально).
  4) Результати: вкладка "Результати" (усі спроби), "Підсумок" (кращий бал на учня) ->
     переносити у "Мрію" вручну.

ПРИВАТНІСТЬ
  Публічний репозиторій НЕ містить списків дітей. Імена вводяться в грі й зберігаються
  лише у приватній Google-таблиці. Коди роздавати приватно.

--- ДЕ ЗУПИНИЛИСЬ / ПЛАН НА ЗАВТРА -----------------------------------------
